# Northstar Credit Portfolio

A Streamlit credit-risk dashboard powered by reproducible synthetic loan data. It includes portfolio KPIs, segment and state filters, booking-window filtering, a PD stress scenario, vintage trends, account-level detail, and CSV export.

All records are mocked. The PD, default, and expected-loss values are illustrative and are not suitable for underwriting or forecasting.

## Run

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```
